# Java Console-Based Quiz Application

A simple interactive Quiz Console Application developed using Core Java. The application displays multiple-choice questions, accepts user answers through the console, evaluates responses, and calculates the final score.

### Features
- Displays multiple-choice questions with four options.
- Accepts user input through the Java Scanner class.
- Stores questions and answers using Java arrays.
- Uses Object-Oriented Programming (OOP) concepts.
- Compares user answers with correct answers.
- Calculates and displays the final quiz score.

### Technologies Used
- Java
- Core Java
- Object-Oriented Programming (OOP)
- Arrays
- Classes and Objects
- Constructors
- Getters and Setters
- Scanner Class
- Loops and Conditional Statements

### Project Structure
- `Main.java` – Application entry point.
- `Question.java` – Question model containing question details and options.
- `QuestionService.java` – Handles quiz execution, answer collection, and score calculation.

### How to Run
1. Clone the repository.
2. Open the project in IntelliJ IDEA or Eclipse.
3. Compile the Java files.
4. Run `Main.java`.
5. Answer the questions displayed in the console and view your final score.
